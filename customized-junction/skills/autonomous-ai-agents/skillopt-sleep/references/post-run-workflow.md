# Post-Run Workflow

After a successful run (gate=accept), follow this workflow to apply and commit the improvements.

## 0. Cleanup CLAUDE.md (if generated)

SkillOpt may generate a CLAUDE.md at the project root during the run. This file should be deleted before committing:

```bash
cd /path/to/project
if [ -f CLAUDE.md ]; then
  rm -f CLAUDE.md
  echo "Deleted CLAUDE.md"
fi
```

**Why:** The generated CLAUDE.md is not part of the optimization and should not be committed. It's a side effect of the claude backend's isolated execution.

## 1. Adopt the Changes

```bash
cd /path/to/SkillOpt
python -m skillopt_sleep adopt \
  --project "/path/to/project" \
  --claude-home "/path/to/project/.skillopt-exp/skill-name/claude-home" \
  --target-skill-path "/path/to/project/.claude/skills/category/skill-name/SKILL.md" \
  --staging "/path/to/project/.skillopt-sleep/staging/YYYYMMDD-HHMMSS"
```

This applies the accepted edits to the target SKILL.md and CLAUDE.md files.

## 2. Commit to Git

```bash
cd /path/to/project
git add .claude/skills/category/skill-name/SKILL.md CLAUDE.md
git commit -m "Apply SkillOpt-Sleep optimization (night N, staging YYYYMMDD-HHMMSS)

- baseline: X.XXX → candidate: Y.YYY (+Z.Z%)
- gate: accept_new_best
- Added N new rules to SKILL.md:
  * RULE_NAME_1 (brief description)
  * RULE_NAME_2 (brief description)
  * ...

Generated by SkillOpt-Sleep with tasks.vN.json (M tasks)"
```

## 3. Push to Remote

```bash
git push origin <branch-name>
```

## 4. Verify

Check that:
- The commit appears in git log
- The changes are pushed to the remote repository
- The staging directory is listed in `.skillopt-sleep/staging/`

## Staging Directory Naming

Staging directories use timestamp-based naming: `YYYYMMDD-HHMMSS` (e.g., `20260715-064220`). This allows you to:
- Identify when each run occurred
- List runs chronologically with `ls -lt`
- Reference specific runs in commit messages

## Example: Full Workflow

```bash
# 1. Adopt changes from night 19 staging
cd /d/workspace/SkillOpt
python -m skillopt_sleep adopt \
  --project "D:/workspace/outlook-tencent-metting" \
  --claude-home "D:/workspace/outlook-tencent-metting/.skillopt-exp/outlook-tencent-meeting-hybrid-en/claude-home" \
  --target-skill-path "D:/workspace/outlook-tencent-metting/.claude/skills/computer-use/outlook-tencent-meeting-hybrid-en/SKILL.md" \
  --staging "D:/workspace/outlook-tencent-metting/.skillopt-sleep/staging/20260715-064220"

# 2. Commit
cd /d/workspace/outlook-tencent-metting
git add .claude/skills/computer-use/outlook-tencent-meeting-hybrid-en/SKILL.md CLAUDE.md
git commit -m "Apply SkillOpt-Sleep optimization (night 19, staging 20260715-064220)

- baseline: 0.792 → candidate: 1.000 (+26.0%)
- gate: accept_new_best
- Added HARD PRE-EXECUTION BLOCKING RULE to SKILL.md:
  * Verifies Execution Plan completeness before execution
  * Prevents mid-step truncation
  * Blocks execution until all 5 steps are fully present

Generated by SkillOpt-Sleep with tasks.v2.json (15 tasks)"

# 3. Push
git push origin restore-skills
```
